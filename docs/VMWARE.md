# VMware Workstation

Профиль `vmware` включает VMware guest tools в headless-режиме для Wayland. Виртуальная графика SVGA поддерживается модулем `vmwgfx`, пользовательская графика — Mesa.

## Ручной тест V3

Владелец установил NixOS 26.11 с ядром 6.18.64 из официального Minimal ISO. ВМ работала с UEFI, Ryzen 9 9950X3D, 8 ГиБ RAM и виртуальным диском 30 ГиБ, где FAT32 ESP занимал 1 ГиБ, остальное отводилось под Btrfs. После исправлений вручную подтвердились Niri, DMS, Kitty, Fish, Ly, Python 3.14.10 через `python`, русская раскладка, сеть с DNS Яндекса, вход, `sudo` и первая генерация. Корень использовал `compress=zstd:3,noatime`. Занято 5,62 ГиБ на диске, после загрузки использовалось около 1,59 ГиБ RAM.

В ходе теста отдельно исправлялись подтверждение в английском TTY, параметры и распознавание Btrfs, слишком короткие сетевые тайм-ауты. VS Code отключили после двух зависаний загрузки на 12 КиБ. Minegrub показал неверную дату первой генерации. Эти сценарии исправлены и покрыты регрессиями V3.1. Повторный полный прогон V3.1 в VMware остаётся отдельной проверкой.

## Чистая проверка V3.1

1. Новая гостевая x86_64 ВМ с прошивкой UEFI, отдельным виртуальным диском от 32 ГиБ и NixOS Minimal ISO. Для графического теста подходят 4 vCPU и 6 ГиБ RAM. В сценарии отсутствуют диски хоста и passthrough.
2. Только на тестовом диске создаются GPT, отдельный ESP 1 ГиБ с FAT32 и корень Btrfs. Для отрицательной проверки сначала выбирается неверный ESP или раздел с чужой точкой монтирования. План должен быть отклонён.
3. Из Live запускается `sudo bash install.sh --dry-run`. Проверяются подсказка `vmware`, переключатель компонента, возврат между разделами меню и неизменность точек монтирования. Затем выполняется обычная установка с Niri + DMS, после завершения ISO извлекается.
4. После загрузки проверяются вход с выбранным паролем, `sudo -v`, загрузчик, Niri, Ly, звук, запуск Firefox через Vicinae и фон DMS. Проверка файловых систем:

   ```bash
   findmnt -no SOURCE,FSTYPE,OPTIONS /
   findmnt -no SOURCE,FSTYPE,OPTIONS /boot
   python --version
   python3 --version
   lsmod | grep vmwgfx
   journalctl --user -b -u niri -u dms -u vicinae
   ```

5. В GRUB проверяются пункт **NixOS**, метки в **NixOS - All configurations**, прокрутка, выход из подменю, запуск предыдущего поколения и откат. Для визуальной проверки подходят отдельные снимки с 1, 5, 10, 20 и 27 поколениями.
6. На отдельных снимках ВМ проверяются Ext4, повтор после прерывания сборки, отсутствие сети, DNS и свободного места, два графических сеанса в Ly и TTY. Проверка недоступного ядра T2 выполняется через fixtures без подмены аппаратного профиля на ВМ.

```bash
bash installer/tests/run.sh
python3 installer/tests/test_progress.py
nix build --no-link "path:$PWD#checks.x86_64-linux."{installer,components,desktop-matrix,niri-vmware,python-path,minegrub}
```

## Существующая ВМ

Установщик предназначен для чистого диска. Рабочий гость обслуживается через `git pull --ff-only` подходящей ветки и `nixos-rebuild`, сохраняя прежний `hardware-configuration.local.nix`, пользователя и файловую систему. Перед обновлением подходит снимок выключенной ВМ и сохранение рабочего поколения как GC root. Старые поколения удаляются после проверки загрузки нового поколения. [Пересборка и откат](CONFIGURATION.md)
