# Конфигурация

| Путь | Назначение |
| --- | --- |
| `hosts/<профиль>/configuration.nix` | Общие переключатели и настройки устройства |
| `hosts/<профиль>/settings.local.json` | Параметры, выбранные в установщике. Имеют приоритет над исходными значениями хоста |
| `hosts/<профиль>/hardware.generated.local.nix` | Сгенерированные аппаратные параметры |
| `hosts/<профиль>/installer.local.nix` | Подключение локальных файлов к Flake |
| `hosts/<профиль>/niri/` | Дисплеи, масштаб, пользовательский автозапуск |
| `modules/`, `home/`, `configs/` | Системные зависимости, Home Manager, оформление |

В установленной системе `<профиль>` — имя выхода Flake из плана установки, независимо от имени компьютера. Для рабочей установки V2 поддерживается прежний `hardware-configuration.local.nix`. `path:` включает игнорируемые локальные модули. [Локальные данные](../SECURITY-AUDIT.md)

```bash
cd /etc/nixos/NixOS-vladik
sudo git pull --ff-only
sudo nixos-rebuild build --flake "path:$PWD#vmware"
sudo nixos-rebuild boot --flake "path:$PWD#vmware"
```

`boot` применяет поколение при следующей загрузке, `switch` также применяет его в текущем сеансе. Сохранённые поколения доступны в GRUB. Отдельно остаётся тестовый выход `nix build .#vm` из чистого клона. Тестовый образ сохраняет стандартный диск QEMU NixOS с Ext4 и использует тестовую учётную запись `vladik` / `vm-only`. При установке профиля `vm` на виртуальный диск эти настройки гостевого образа отключаются.

## Питание ноутбука

В Niri + DMS действуют следующие начальные значения.

| Действие | Батарея | Сеть |
| --- | --- | --- |
| Дисплей выключается | 2 минуты бездействия | 10 минут бездействия |
| Сессия блокируется | спустя 5 минут после выключения дисплея | спустя 5 минут после выключения дисплея |
| Suspend | после 15 минут бездействия | выключен |
| Закрытие крышки | suspend | suspend |

На MacBook suspend и действие крышки по умолчанию выключены до аппаратной проверки. DMS отсчитывает 7/15 минут до блокировки от последней активности и переключает набор таймеров при изменении питания. Idle inhibitors учитываются DMS. logind обрабатывает крышку, а DMS блокирует сессию перед suspend. Параллельная idle-служба не запускается. Таймеры можно менять в DMS после первого применения. Уже настроенные ненулевые таймеры сохраняются. Plasma использует штатное управление питанием своего сеанса. [Параметры и тесты MacBook](MACBOOK-T2.md)

## Minegrub

Minegrub сохраняет фон, логотип и кнопки Minecraft. Одно прокручиваемое меню показывает до 20 поколений в порядке от новых к старым. Метка `5 - 26_11_2026/15:34` берётся из номера и времени создания ссылки поколения в часовом поясе целевой системы. Стандартные пути загрузки и записи специализаций сохраняются. Для MacBook список GOP-режимов `1024x768,1280x800,auto` доступен через `mySystem.grub.efiVideoMode`. Он не влияет на Niri. При проверке прошивки доступные режимы показывает `videoinfo` в консоли GRUB. Альтернативная тема `world-selection` доступна штатным переключателем.

## Поколения и Nix Store

Поколение — ссылка на неизменяемое системное замыкание в Nix Store. Предыдущее поколение доступно из GRUB. `nixos-rebuild test` применяет конфигурацию до перезагрузки, `boot` обновляет следующий запуск, а `switch` делает оба действия. Откат на предыдущее поколение выполняется `sudo nixos-rebuild switch --rollback`. Поколения не содержат резервных копий пользовательских файлов.

Еженедельная очистка с `--delete-older-than 14d` удаляет старые ссылки, если они больше не являются текущими в профиле. Чтобы закрепить проверенное поколение вместе с ядром T2 и сохранить его в GRUB, подходит отдельный именованный системный профиль. После создания профиля меню обновляется обычным `nixos-rebuild boot` выбранного хоста.

```bash
sudo nix-env --profile /nix/var/nix/profiles/system --list-generations
sudo install -d /nix/var/nix/profiles/system-profiles
sudo nix-env --profile /nix/var/nix/profiles/system-profiles/known_good \
  --set "$(readlink -f /run/current-system)"
nix path-info --closure-size --human-readable /run/current-system
```

Прямая GC root также сохраняет замыкание, но сама по себе не сохраняет пункт меню после удаления ссылки поколения. `nix store gc` освобождает объекты без ссылок. Игры Steam, Flatpak и личные кеши обслуживаются отдельно.

## Python

Python 3 входит в базовую конфигурацию. Системные команды `python` и `python3` используют один интерпретатор. Зависимости проектов задаются в их собственных Flake или виртуальных окружениях.

## Обои

Исходное изображение — `assets/wallpapers/Oboi.jpg`. Замена JPEG в репозитории и пересборка обновляют проектный фон DMS и фон Breeze по умолчанию. Ручные настройки DMS сохраняются. Горячие клавиши Niri находятся в `configs/niri/cfg/keybinds.kdl`.
