# Локальные данные и публикация

`*.local.nix`, `*.local.json` и `firmware/` исключены из Git. Они содержат реальные параметры дисков, настройки установки и при необходимости firmware Broadcom. Путь Flake с префиксом `path:` включает локальные файлы при вычислении и может копировать их в Nix Store. Приватные ключи, пароли и личные данные хранятся вне дерева Flake.

Пароль вводится без эха, передаётся `chpasswd` через stdin и хранится в виде хеша в `/etc/shadow`. Он отсутствует в сохранённых настройках и в аргументах команд. Тестовый пароль QEMU относится только к тестовому гостевому образу.

Установщик работает с уже подготовленными разделами. Проверка монтирования выполняется перед GRUB. На MacBook проверяются раздельные ESP и APFS, GRUB использует EFI fallback, запись в NVRAM и OS Prober отключены. Ключ Cachix T2 закреплён в репозитории; Nix проверяет подпись скачиваемых объектов. [MacBook T2](docs/MACBOOK-T2.md) · [Кеш](docs/BINARY-CACHE.md)

Перед публикацией проверяется список подготовленных к коммиту файлов. Исключения Git не действуют на ранее добавленные файлы. Журнал установки хранится с правами root и может содержать локальные идентификаторы.
