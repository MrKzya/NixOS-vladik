# Совместимость и миграция

## Действующие установки

Для V1/V2 с рабочим диском применяется пересборка из существующего Flake. Формат корня, домашний каталог, пароль, состояние DMS и локальные дисковые параметры сохраняются. В V2 завершён переход от Default, Gaming и Minimal к одной конфигурации хоста. В V3 установочные параметры создаются только для установки через `install.sh`. [Управление конфигурацией](docs/CONFIGURATION.md)

Для QEMU/KVM тестовый образ по-прежнему доступен через `nix build .#vm`. Только этот образ использует тестовый пароль. Установка в обычный диск QEMU задаёт пароль в диалоге.

## История проверок

Для V1 подтверждены запуск QEMU/KVM и чистая установка NixOS 26.05 Minimal в VMware. Проверены Niri, DMS, Ly, Kitty, Fish, оформление, PATH Vicinae и обновление через `nixos-rebuild`.

Для V2 на одном QEMU-хосте граф derivations сократился с 11 736 до 7 119 при неизменном `flake.lock`. Значения описывают граф сборки. Размер реализованных замыканий и расход диска не измерялись.

Для V3 прошли ShellCheck, тесты с подменой команд, вычисление всех профилей и `nix flake check --no-build` с тестовыми параметрами дисков. Готовое ядро и модули T2 скачаны и проверены Nix. Установка V3 с последующей загрузкой ещё не проводилась. [Сценарий проверки в VMware](docs/VMWARE.md) · [Объекты кеша](docs/BINARY-CACHE.md)
