# История изменений

## V3.2 · ветка installer

- Для MacBook включён проверенный владельцем suspend. DMS мигрирует таймеры питания, выключает дисплей через Niri DPMS и блокирует сеанс перед сном.
- У F1/F2 и F5/F6 отдельные шкалы с 0%. Подсветка клавиатуры восстанавливается после автоотключения и сна. У Ly крупный консольный шрифт Retina.
- Исправлены права запуска xremap и выбор интерфейса Fn. Command управляет окнами, вкладками и навигацией, редактирование использует Ctrl.
- Добавлен отключённый по умолчанию эксперимент с коротким трёхпальцевым свайпом в Niri 26.04.
- Karing получает библиотеки Flutter и зависимости System Proxy из wrapper. Ограничение TUN описано в диагностике. TG WS Proxy 1.12.0 собирается из исходников и проверяет стек GTK/Tk при сборке.

## V3.1 · ветка installer

- Английский ASCII-интерфейс, `INSTALL`, проверка UEFI в dry-run и категории компонентов.
- Безопасная проверка Btrfs с `rescue=nologreplay` и сверкой физического источника монтирования.
- Сохранение и экспорт плана без пароля. При восстановлении сверяются идентификаторы разделов и GPT-диска.
- Раздельные сетевые проверки IPv4/IPv6, повтор временных сбоев, прогресс по событиям Nix и диагностика зависших загрузок. По запросу пользователя необязательное приложение можно отложить с повторным использованием целевого Store.
- Minegrub показывает текущую систему и все поколения с реальными датами ссылок. Добавлены настройки по умолчанию для часового пояса, locale, раскладок и 24-часовых часов.
- Описаны результаты V3 в VMware и обновление существующей установки MacBook с 6.18.55.

## V3 · ветка installer

- Проверка GPT ESP через blkid внутри nixos-enter, диагностика сетевых сбоев и импорт Broadcom firmware из архива.
- Изолированные Command-сочетания, управление подсветкой клавиатуры и масштаб 1.6 для MacBook.
- Таймеры DMS для ноутбуков, Python 3 и прокручиваемое меню Minegrub с короткими метками поколений.

- Интерактивная установка для ThinkPad, VMware, QEMU/KVM и Intel MacBook T2 с готовых разделов GPT.
- Проверки ESP и идентификаторов, Btrfs с Zstd по умолчанию, совместимость с Ext4 и dry-run.
- Параметры хоста, компоненты V2, восстановление DNS, установка GRUB и пароль через stdin.
- Готовое ядро T2 6.18.35 с проверкой подписи и запретом сборки при отсутствии бинарных объектов.
- Установленный профиль `vm` отделён от тестового запуска `nix build .#vm`.

## V2

- Одна системная конфигурация на хост. Независимые переключатели Niri, Plasma и приложений.
- Локальная аппаратная конфигурация, защита Linux ESP на MacBook, еженедельный GC и оптимизация Store.

## V1

- Перенос окружения Arch Linux на NixOS. Niri, DMS, Vicinae, Ly, Kitty, Fish и Minegrub.
- Исправление PATH Vicinae и поддержка pactl. Общий JPEG-фон DMS и Plasma.
