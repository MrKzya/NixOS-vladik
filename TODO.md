# Проверки перед выпуском

1. VMware. В V3 после ручных исправлений подтверждены установка с Btrfs и первый вход. Повторить на V3.1 с автоматическим восстановлением плана и наблюдением за загрузкой VS Code. Затем проверить Ext4, прерывание, прокрутку GRUB и откат. [Сценарий](docs/VMWARE.md)
2. ThinkPad. Проверка Wi-Fi, Bluetooth, графики, звука, батареи, UEFI и графического сеанса.
3. MacBookAir9,1. Загрузка через Option с готовым ядром и контроль macOS. Wi-Fi с передачей данных, отдельный тест Bluetooth, клавиши Fn и Command, ввод после нескольких циклов сна, подсветка и отзывчивость GOP Minegrub. [T2](docs/MACBOOK-T2.md)
4. Live ISO с установщиком. После аппаратных тестов добавить два выхода Flake на основе `installation-cd-minimal.nix`. Для T2-образа использовать закреплённый модуль ядра и настройки ранней загрузки t2linux. Встроить снимок ветки installer с `flake.lock` и предоставить запуск из локальной копии в Live. Критерии выпуска образов включают воспроизводимость, подписи, запуск в UEFI и полный набор Live-утилит.
5. Объединение в `main` после аппаратных проверок и отдельного решения владельца.
