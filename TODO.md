# Проверки на целевых устройствах

- [x] V1 собрана и загружена через QEMU/KVM на ThinkPad под Arch. Проверены Niri + DMS, Plasma, Ly, терминальное окружение и оформление. Для Niri на Arch использовались VirGL и nixGLIntel.
- [x] V1 установлена из официального Minimal ISO в VMware Workstation и развёрнута из GitHub. Проверены Niri, DMS, Ly, Vicinae с исправленным PATH, Kitty, Fish, Starship, обои и обновление через nixos-rebuild.
- [ ] Применить V2 в существующем госте [по руководству VMware](docs/VMWARE.md#переход-рабочей-vmware-на-v2). Проверить выбор Niri и Plasma через Ly при обоих включённых окружениях, TTY, запуск приложений Vicinae, звук, фон и откат. Проверить реальные размеры до удаления старых поколений.
- [ ] На целевом Intel MacBook определить модель и карту дисков, сохранить резервную копию macOS, проверить T2 Live и подготовить отдельный Linux ESP. После этого заполнить локальный аппаратный модуль и проверить установку/загрузку обеих ОС. [MacBook T2](docs/MACBOOK-T2.md)
- [ ] На MacBook проверить Wi‑Fi/Bluetooth, ввод в initrd, тачпад, звук, яркость, подсветку клавиатуры, графику, Touch Bar по модели, вентиляторы и suspend/resume. Установить нужный масштаб после `niri msg outputs`.
- [ ] Снять реальные данные ThinkPad для нативной установки. Проверка QEMU на ThinkPad не подтверждает работу его физического загрузчика и периферии.
- [ ] В Linux запустить `checks.x86_64-linux.niri-*` и `shell-config`. Графические проверки включают IPC, блокировку DMS и Wayland-порталы.
- [ ] Проверить Karing и TG WS Proxy с локальными настройками. Привилегированный TUN Karing остаётся отдельным вопросом.
